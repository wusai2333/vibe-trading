# 个股 + 板块筛选器使用报告（2026-08-07）

> 两个独立筛选器，都定位为**相对排序工具**——按强度排序候选项，不做绝对收益预测。
> 脚本与最新输出都在 `reports/data/`，可随时重跑。

---

## 一、个股筛选器（gtja171 因子）

**脚本**：`reports/data/gtja171_screener.py`
**用法**：
```bash
python gtja171_screener.py --top 15 --smooth 10 [--universe PATH]
```
- `--universe`：候选池 JSON（含 `codes` 数组），默认用沪深 300 名单 `csi300_cons.json`
- `--smooth`：因子滚动平滑窗口（交易日），默认 10
- 输出：`screener_latest.json`（严格 JSON，含 pct_rank / 20日动量 / 现价）

## 二、板块筛选器（行业轮动）

**脚本**：`reports/data/sector_screener.py`
**用法**：
```bash
python sector_screener.py --top 3 [--lookback-days 250]
```
对沪深 300 十个行业指数（000928-000937）按 20 日 + 60 日动量的排名合成打分，rank 1 = 最强。
输出：`sector_screener_latest.json`

|---|---|---|---|

**怎么读**：医药卫生是唯一 20 日、60 日动量双正的板块，动能最稳；能源/材料是短线反弹（20 日强、60 日仍负），持续性待观察。这是轮动信号，不是买入承诺。

## 三、两个筛选器怎么配合

1. **板块先行**：先用板块筛选器定方向（当前医药卫生最强）
2. **个股收敛**：把个股筛选结果按板块归类，优先看强势板块内的个股
3. **叠加动量过滤**：个股筛选里 20 日动量为负的（蓝思、豪威、浪潮），除非有独立逻辑，否则降权

当前交叉结果：医药卫生板块最强，个股名单里只有**科伦药业**（002422，分位 92%）落在该板块——它同时满足"板块强 + 个股因子强 + 动量 +3.1%"三个条件，是今日两个筛选器唯一重合的标的。

## 四、复现与局限

```bash
cd reports/data
python gtja171_screener.py --top 15 --smooth 10   # 个股，约 3 分钟
python sector_screener.py --top 3                  # 板块，约 7 秒
```

局限：
- 个股池是**当前**沪深 300 名单，有幸存者偏差（无逐日成分）
- 板块用指数动量，未含个股分化；医药卫生指数强不代表所有医药股强
- 因子为单一 gtja171，未做多因子组合
- 相对排序工具，不构成投资建议，实盘需自加风控与成本
